โฟลเดอร์รูปภาพสายพันธุ์สุนัข DogPedia (images/breeds/)
=============================================================================

ปัจจุบันระบบได้สร้าง "รูปภาพจำลอง Placeholder (.svg)" ให้ครบทั้ง 30 สายพันธุ์แล้ว
รูปภาพทั้งหมดเป็นแบบเวกเตอร์ (Vector Graphic) คมชัด สวยงาม แยกตามโทนสีของกลุ่มขนาด
และสามารถเปิดใช้งานได้ทันทีโดยไม่ต้องต่ออินเทอร์เน็ต

-----------------------------------------------------------------------------
วิธีเปลี่ยนเป็นรูปภาพจริงของคุณภายหลัง (2 วิธีง่ายๆ)
-----------------------------------------------------------------------------

วิธีที่ 1 : นำไฟล์รูปจริงมาวางในโฟลเดอร์นี้ แล้วเปลี่ยนที่โค้ด HTML (แนะนำ)
  1. นำไฟล์รูปถ่าย เช่น pomeranian.jpg, corgi.png มาใส่ไว้ในโฟลเดอร์ images/breeds/
  2. เปิดไฟล์ breeds.html หรือ index.html
  3. มองหาแอตทริบิวต์ src ของการ์ดที่ต้องการ แล้วเปลี่ยนชื่อไฟล์ เช่น:
     จากเดิม:
       <img src="images/breeds/pomeranian.svg" class="card-img-top breed-card-img" alt="...">
     เปลี่ยนเป็น:
       <img src="images/breeds/pomeranian.jpg" class="card-img-top breed-card-img" alt="...">

วิธีที่ 2 : ใส่เป็น URL ลิงก์รูปภาพจากอินเทอร์เน็ตโดยตรง
  คุณสามารถใส่ URL ของภาพถ่ายจริงได้ทันที เช่น:
  <img src="https://images.unsplash.com/photo-..." class="card-img-top breed-card-img" alt="...">

-----------------------------------------------------------------------------
ขนาดรูปภาพที่แนะนำ
-----------------------------------------------------------------------------
- สัดส่วน: 3:2 หรือ 16:9
- ขนาดที่เหมาะสม: 600 x 400 พิกเซล (ระบบมี object-fit: cover ช่วยตัดส่วนภาพให้สวยงามพอดีการ์ดอัตโนมัติ)
